# WADEE

会話のきっかけを探したり、自分の話題を登録したりできる Flutter 製 Android プロトタイプです。

## 起動

1. このフォルダを Android Studio で開く
2. Flutter / Dart の依存関係を取得する
3. Android エミュレーターまたは実機を選択して実行する

コマンドラインからは次のコマンドでも起動できます。

```shell
flutter pub get
flutter run
```

## 実装している機能

- 定番話題36件と9カテゴリ
- カテゴリによる話題の絞り込み
- 話題の詳細表示とお気に入り登録
- 自作話題の追加・編集・削除
- 自作話題とお気に入りの端末内保存（`shared_preferences`）

AI、ニュース取得、ログイン、クラウド同期などは v1 プロトタイプの対象外です。
